## Download

- **Windows desktop app:** download **Pratice-Code-Setup.exe**, run it and open the Pratice Code shortcut. Python, Microsoft WebView2 and the complete study collection are bundled. No separate runtime download is needed.
- **Offline website:** download **Pratice-Code-Offline.zip**, extract the complete folder and run **Install and Start.cmd** on Windows. The ZIP includes the Python runtime. On macOS/Linux use your installed Python with `python3 install.py`.
- **Live website:** https://laxtline.github.io/Pratice-Code/

## Included

- One workspace for Coding Lab, practice, 30 courses, 145 lessons, exams, interviews, revision and progress.
- 4,097 imported question records, retained reference topics and judged input/output exercises.
- 14,652 preparation files and books, including PDF-guided Level wise tracks.
- Python and JavaScript function practice, SQLite exercises and HTML/CSS/JavaScript previews.
- Browser autosave and progress export/import. The desktop/local edition also keeps a private folder backup.

The live website runs Python and JavaScript in your own browser. C/C++ and Java need the desktop/local edition and an installed compiler/JDK. Local practice tests are independent training exercises, not official platform submissions.
